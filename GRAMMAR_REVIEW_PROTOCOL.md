# Independent Sanskrit expert review protocol

Status: **NOT COMPLETED**. The project has no independent Sanskrit expert sign-off.

For each item in `grammar/review_corpus.json`, the reviewer should independently assess surface segmentation, lemma, gender, vacana, vibhakti, predicate valency, kāraka candidates, sūtra attribution, exceptions and grammatical plausibility. Record an identifiable reviewer, qualifications, date, textual sources, corrections and a signed approval or rejection.

The current corpus is especially **not** a gold standard for syntactic role disambiguation: neuter `phalam` shows nominative/accusative syncretism, and frame-based nominal candidates do not enforce sentence-level uniqueness or agreement.

Approval criterion: each required item independently confirmed; disputed analyses marked contested, not silently accepted. All substantive changes require corpus version bump, repeat tests and certificate regeneration.
