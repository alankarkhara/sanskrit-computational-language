# SCL v0.8.8 — Grounded two-process task execution

**Status:** experimental, restricted pure-Int64 arithmetic; not a production multi-agent language and not mechanically proved.

New: `core080/grounded088.py`, `core080/examples/grounded_agents_088.scl`, `grounded088_cli.py`, `agent088_peer.py`, unit/adversarial tests, process integration test, and `GROUNDED_TASKS_088.md`.

The original Pāṇinian-inspired roles remain structurally distinct: `kartṛ` (requester/authorized operator), `pratigrahītṛ` (recipient), `vastu` (typed object), `adhikāra` (operation authority), `kriyā` (task), `prabhāva` (effect class). This is an adaptation, not a claim of faithful complete Sanskrit grammar.

This release closes the demonstrable arithmetic reference/operation/certificate/independent-process gap under an explicit trust model, not the open-ended AI dialogue or external authority gap.
